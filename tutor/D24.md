# Day 24: JSON: data that travels

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Read and write the format every app and website uses.

## Key points
- JSON is the text format apps use. It looks like Python dictionaries and lists.
- `json.loads(text)` and `json.dumps(data)` convert between text and data.
- `json.load(f)` and `json.dump(data, f)` do the same straight with a file. `indent=2` makes it neat.
- Dig into nested data one step at a time: `shots[0]["mins"]`.

## Task 1: Read a call time
`call.json` holds one small dictionary. Read the whole file as text with `f.read()`, turn it into data with `json.loads`, then show the unit and the call time:

`Imvana call: 06:00`

Hints, in order:
1. `data` is now a dictionary. Printing it shows curly brackets and quotes.
2. Look up the two keys: `data["unit"]` and `data["call"]`.
3. print(data["unit"], "call:", data["call"])

Answer:
```python
import json
with open("call.json") as f:
    text = f.read()
data = json.loads(text)
print(data["unit"], "call:", data["call"])
```

## Task 2: Total the shots
`shots.json` is a list of dictionaries. Show each shot and its minutes, then the total minutes:

`1A 20`
`1B 30`
`2A 15`
`Total: 65`

Hints, in order:
1. Each `s` is a dictionary with the keys `shot` and `mins`. Print both on one line.
2. Also add the minutes to `total`. In JSON a number is already a number, so no int() needed.
3. Inside the loop: print(s["shot"], s["mins"]) and then total += s["mins"]

Answer:
```python
import json
with open("shots.json") as f:
    shots = json.load(f)
total = 0
for s in shots:
    print(s["shot"], s["mins"])
    total += s["mins"]
print("Total:", total)
```

## Task 3: Add a crew member and save
`crew.json` is a list of people. Add `{"name": "Kay", "role": "Boom"}` to the end, save the list back into `crew.json` with `indent=2`, and show how many people there are now, like:

`Crew now: 3`

Hints, in order:
1. Saving means opening the file again, this time to write.
2. Open with mode "w", then use json.dump(crew, f, indent=2).
3. with open("crew.json", "w") as f:  then  json.dump(crew, f, indent=2)

Answer:
```python
import json
with open("crew.json") as f:
    crew = json.load(f)
crew.append({"name": "Kay", "role": "Boom"})
print("Crew now:", len(crew))
with open("crew.json", "w") as f:
    json.dump(crew, f, indent=2)
```
