# Day 8: Repeat until done

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Make Python repeat steps for you, then stop at the right moment.

## Key points
- `while condition:` repeats the pushed-in lines as long as the condition is True.
- A counter (`n = 1`, then `n += 1`) makes the loop move forward.
- `break` leaves the loop at once. `while True:` plus `break` is a common pattern.
- If the condition never turns False you have an infinite loop. Check the counter.

## Task 1: The loop that never starts
This loop should show `1`, `2`, `3` on separate lines, but it shows nothing. The question is False from the very first check. Change ONE thing so it works.

Hints, in order:
1. A while loop only runs if the question is True at the start. Is 1 > 3 True?
2. You want it to keep going while n is small. Which comparison says that?
3. Change the second line to: while n <= 3:

Answer:
```python
n = 1
while n <= 3:
    print(n)
    n += 1
```

## Task 2: Slate takes
Ask how many takes. Then show `Take 1`, `Take 2` and so on up to that number. Example:

`How many takes? 2`
`Take 1`
`Take 2`

Hints, in order:
1. Copy the shape from the Watch example. The 3 there becomes total.
2. while take <= total: then print an f-string, then add 1 to take. All pushed in.
3. while take <= total:
    print(f"Take {take}")
    take += 1

Answer:
```python
total = int(input("How many takes? "))
take = 1
while take <= total:
    print(f"Take {take}")
    take += 1
```

## Task 3: Count the crew
Keep asking `Crew name (or done)? ` again and again. Stop when the answer is `done`. Count the names you were given and show how many at the end. Example:

`Crew name (or done)? Ana`
`Crew name (or done)? done`
`1 crew`

Hints, in order:
1. Start with while True: so it keeps asking. Inside, use input() and store the answer.
2. After asking, check: if name == "done": then break. Otherwise add 1 to count.
3. while True:
    name = input("Crew name (or done)? ")
    if name == "done":
        break
    count += 1

Answer:
```python
count = 0
while True:
    name = input("Crew name (or done)? ")
    if name == "done":
        break
    count += 1
print(f"{count} crew")
```
