# Day 1: Make the computer talk

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Write your first three programs with one word: print.

## Key points
- A program is a list of steps. Python reads them top to bottom.
- print("text") shows text on the screen.
- Text goes inside quotes. Text in quotes is called a string.
- An error names the line. Read it, fix it, run again.

## Task 1: Say hello
Write one line that shows exactly: `Hello, Matthew!`

Hints, in order:
1. You need the word print, then round brackets, then the text in quotes.
2. The shape is print("your text here"). Check the comma and the exclamation mark.
3. Type exactly: print("Hello, Matthew!")

Answer:
```python
print("Hello, Matthew!")
```

## Task 2: Call sheet header
The lines are in the wrong order and one is missing. Make it show these three lines, in this order:

`CALL SHEET`
`Shoot day 1 of 5`
`Crew call: 06:00`

Hints, in order:
1. Python reads top to bottom, so the line you want first must be on line 1.
2. Swap the two lines, then add a third print line at the bottom.
3. The third line is print("Crew call: 06:00"). Capital letters and spaces must match.

Answer:
```python
print("CALL SHEET")
print("Shoot day 1 of 5")
print("Crew call: 06:00")
```

## Task 3: Fix the three bugs
Each line has one mistake. Tap Run, read the error, fix that line, run again. When all three are fixed it shows:

`Lights`
`Camera`
`Action`

Hints, in order:
1. Python stops at the first error it finds. Fix the line it names, then run again to find the next one.
2. Look for: a missing closing quote, a capital letter where it should be small, and a missing closing bracket.
3. Line 1 needs a quote after Lights. Line 2 must start with a small p. Line 3 needs a ) at the end.

Answer:
```python
print("Lights")
print("Camera")
print("Action")
```

## Editor tip (VS Code): What VS Code actually is
VS Code is a text editor made for code. That is all. It does not run Python itself: it is the desk you work at, and Python is the worker. **Cursor** is a copy of VS Code with an AI helper built in, so every button you learn here works the same there. Learn one, know both.

Try at the PC: Open VS Code and find four areas: the icon strip on the far left, the big empty middle (the editor), the top menu, and the blue bar at the bottom. Just look. Change nothing.
