# Day 19: Borrow other people's tools

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Import maths, dice and dates, and move a time forward by 90 minutes.

## Key points
- `import module` brings in ready-made tools. Use them as `module.tool(...)`.
- `math.ceil` rounds up, `math.floor` rounds down.
- `random.choice` picks one. `random.shuffle(list)` mixes the list in place.
- `strptime` turns text into a time, `timedelta` moves it, `strftime` turns it back into text.

## Task 1: How many vans
9 crew and 4 seats per van. Show how many vans are needed, rounding UP. It must show:

`3`

Hints, in order:
1. You need a tool that rounds up. It lives in the math module you already imported.
2. The tool is math.ceil(...). Put crew divided by seats inside the brackets, and print the result.
3. print(math.ceil(crew / seats))

Answer:
```python
import math

crew = 9
seats = 4
print(math.ceil(crew / seats))
```

## Task 2: Ready at
Crew call is 05:30. Ask `Minutes? ` and add that many minutes. Show the time as hours and minutes, like `Ready at 07:00` when 90 is typed.

Hints, in order:
1. Make a new time by adding timedelta(minutes=mins) to call.
2. ready = call + timedelta(minutes=mins). Then turn it back into text with ready.strftime("%H:%M").
3. print("Ready at", ready.strftime("%H:%M"))

Answer:
```python
from datetime import datetime, timedelta

call = datetime.strptime("05:30", "%H:%M")
mins = int(input("Minutes? "))
ready = call + timedelta(minutes=mins)
print("Ready at", ready.strftime("%H:%M"))
```

## Task 3: Lunch queue
Shuffle the crew list, then show the order on one line, like `Lunch queue: Thabo, Sipho, Naledi, Lerato`. The order will be different with different shuffles, so the lesson fixes the dice for you.

Hints, in order:
1. random.shuffle mixes the list itself. Write it on its own line, with no equals sign.
2. After random.shuffle(crew), join the names with ", ".join(crew).
3. print("Lunch queue:", ", ".join(crew))

Answer:
```python
import random

crew = ["Sipho", "Lerato", "Thabo", "Naledi"]
random.shuffle(crew)
print("Lunch queue:", ", ".join(crew))
```

## Editor tip (VS Code): Typing commands yourself
The Run button only types a command into the terminal for you. You can type it yourself: `python hello.py`. Professionals mostly work this way. The **Up arrow** brings back your last command, `cls` wipes the screen, `dir` lists the files in the folder.

Try at the PC: Open the terminal with Ctrl+` and type `dir`, then `python hello.py` (use `py hello.py` if python is not found). Press Up arrow and Enter to run it again. Type `cls`.

## On the PC: Get your PC ready and run your first file
Until now you typed code into this lesson page. Real programmers keep code in files on their own computer and run it there. Today you check that Python is installed, open VS Code, make one file and run it. It is only a few clicks. If anything looks different, do not panic: read the note under the step.

1. Press the Windows key on your keyboard, type `powershell`, and press Enter. A blue or black window opens with a blinking cursor. This window is called the terminal.
2. In that window type `python --version` and press Enter. You should see `Python 3.12.` followed by a number. If it says Python was not found, type `py --version` instead and use `py` instead of `python` for the rest of the steps. Close the window with the X.
3. Make a folder for your files. Press Windows key + E to open File Explorer. In the list on the left click **Documents**. Right-click on empty white space, choose **New**, then **Folder**. Type `Python 30 Work` and press Enter.
4. Press the Windows key, type `Visual Studio Code`, and press Enter. VS Code opens. If a Welcome tab shows, ignore it. If a box asks about trust, click **Yes, I trust the authors**.
5. In VS Code click **File** at the top left, then **Open Folder**. Click **Documents**, click the **Python 30 Work** folder, then click **Select Folder**. If it asks about trust again, click **Yes, I trust the authors**. The left panel now shows PYTHON 30 WORK. It is empty. That is correct.
6. Move your mouse over the words PYTHON 30 WORK in the left panel. A few tiny icons appear. Click the first one (a page with a plus), type `hello.py` and press Enter. A blank file opens in the big middle area. This middle area is the editor.
7. Click inside the editor and type: `print("Hello from my PC")`. Press Ctrl+S to save. While a file is unsaved, the tab at the top shows a white dot. After saving the dot goes away. If a box pops up at the bottom right offering the Python extension, click **Install**. It is safe and adds a Run button.
8. Open the terminal inside VS Code: click **Terminal** in the top menu, then **New Terminal**. A panel opens at the bottom. The last line ends with `Python 30 Work>` and a blinking cursor.
9. Type `python hello.py` and press Enter. Below it you should see `Hello from my PC`. That is your program, running from a real file. If it says python is not recognized, type `py hello.py` instead.
10. Try a module. Replace the line in hello.py with two lines: `import math` and then `print(math.sqrt(144))`. Press Ctrl+S, click in the terminal, press the Up arrow key to bring back the last command, and press Enter. You should see `12.0`. If you still see the old text, you forgot Ctrl+S.
