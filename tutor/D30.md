## Task 1: Pay for one person
The day rate covers up to 10 hours. Each hour over 10 pays the day rate divided by 10, times 1.5. Finish the program. Examples:

R1500 for 8 hours is `Pay: R1500.00`
R1500 for 12 hours is `Pay: R1950.00`

Hints, in order:
1. You only need an if. The overtime hours are hours - 10.
2. Each overtime hour pays day_rate / 10 * 1.5. Multiply that by (hours - 10).
3. if hours > 10:
    pay = day_rate + (hours - 10) * day_rate / 10 * 1.5

Answer:
```python
day_rate = int(input("Day rate? "))
hours = int(input("Hours? "))
pay = day_rate
if hours > 10:
    pay = day_rate + (hours - 10) * day_rate / 10 * 1.5
print(f"Pay: R{pay:.2f}")
```

## Task 2: The whole crew
Now the rule is a function called `pay`, and the crew is in `crew.csv` (columns name, role, rate, hours). Loop over the crew and print one line each, like:

`Sam (Gaffer): R1950.00`

Hints, in order:
1. row["rate"] and row["hours"] are text. Wrap each in int(...) before using them.
2. amount = pay(int(row["rate"]), int(row["hours"])) gives the money for that row.
3. print(f"{row['name']} ({row['role']}): R{amount:.2f}")

Answer:
```python
import csv

def pay(day_rate, hours):
    """Pay for one person for one day."""
    if hours <= 10:
        return day_rate
    return day_rate + (hours - 10) * day_rate / 10 * 1.5

with open("crew.csv", newline="") as f:
    for row in csv.DictReader(f):
        amount = pay(int(row["rate"]), int(row["hours"]))
        print(f"{row['name']} ({row['role']}): R{amount:.2f}")
```

## Task 3: The invoice file
Finish the tool. Add up a subtotal, add VAT at 15 percent, and write everything to `invoice.txt`, then print `Saved invoice.txt`. For the first crew the file holds:

`INVOICE`
`Sam (Gaffer): R1950.00`
`Thandi (Grip): R1200.00`
`Lerato (Sound): R1800.00`
`Pieter (Spark): R1305.00`
`Subtotal: R6255.00`
`VAT 15%: R938.25`
`Total: R7193.25`

Hints, in order:
1. Start with subtotal = 0 before the loop. Inside the loop add: subtotal += amount.
2. After the loop: vat = subtotal * 0.15, then three more lines.append(...) for Subtotal, VAT 15% and Total (subtotal + vat).
3. To write: with open("invoice.txt", "w") as f: then f.write("\n".join(lines) + "\n"). Then print("Saved invoice.txt").

Answer:
```python
import csv

def pay(day_rate, hours):
    """Pay for one person for one day."""
    if hours <= 10:
        return day_rate
    return day_rate + (hours - 10) * day_rate / 10 * 1.5

lines = ["INVOICE"]
subtotal = 0
with open("crew.csv", newline="") as f:
    for row in csv.DictReader(f):
        amount = pay(int(row["rate"]), int(row["hours"]))
        subtotal += amount
        lines.append(f"{row['name']} ({row['role']}): R{amount:.2f}")
vat = subtotal * 0.15
lines.append(f"Subtotal: R{subtotal:.2f}")
lines.append(f"VAT 15%: R{vat:.2f}")
lines.append(f"Total: R{subtotal + vat:.2f}")
with open("invoice.txt", "w") as f:
    f.write("\n".join(lines) + "\n")
print("Saved invoice.txt")
```

## On the PC: Ship the invoice tool on GitHub
A finished tool that other people can read is worth more than ten half-built ones. You put it online with a README so anyone can see what it does.

1. Open VS Code. Click File, Open Folder, open Python 30 Work, click New Folder, name it `invoice-tool`, then Select Folder. Click Yes to trust it. Open a terminal with Terminal, New Terminal. The line should end with `invoice-tool>`.
2. Make `crew.csv` (New File icon). Type exactly these lines, with made-up names, then Ctrl+S:

name,role,rate,hours
Sam,Gaffer,1500,12
Thandi,Grip,1200,10
Lerato,Sound,1800,9
Pieter,Spark,900,13
3. Make `invoice.py` and type your finished code from task 3 (or type it from the lesson). Save with Ctrl+S.
4. In the terminal type `python invoice.py` and press Enter. You should see `Saved invoice.txt`. Click invoice.txt on the left and check the Total says `R7193.25`. If you see ModuleNotFoundError or a Python-not-found message, use `py invoice.py`.
5. Make `README.md` and write: a title line starting with `# `, one line saying what the tool does, a line that says `Run: python invoice.py`, and a line that explains the crew.csv columns. Save it.
6. Make `.gitignore` with two lines: `invoice.txt` and `.venv/`. Real invoices hold real names and money, so they stay off GitHub. Save it.
7. Type `git init`, press Enter, then `git branch -M main`, then `git add .`, then `git commit -m "Invoice tool v1"`. Type `git status`: it should say nothing to commit, working tree clean.
8. In your browser open github.com, click the plus at the top right, then New repository. Name it `invoice-tool`, pick Public, do not tick any extra boxes, click Create repository.
9. Copy the two lines under push an existing repository from the command line, and paste them into the terminal one at a time (`git remote add origin ...` then `git push -u origin main`). Approve the sign-in window if it opens.
10. Refresh GitHub. Your files are there and the README is the front page. Copy the web address of the page.
11. Send the link to one person you respect, with one line saying what it does. Then pick your next tool from PLAN.md and make a new folder for it. You finished the course.
