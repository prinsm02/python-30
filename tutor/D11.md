# Day 11: Lists: a shot list in code

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Keep a whole crew or shot list in one variable and grab any item.

## Key points
- A list holds many things in order: `["a", "b", "c"]`.
- Spots count from 0. `-1` is the last item.
- `len`, `append` and `in` count, add and check.
- `mylist[1] = x` changes an item. A spot that does not exist gives IndexError.

## Task 1: First and last
The crew list is ready. Print the first name, then the last name, each on its own line:

`Sam`
`Ayanda`

Hints, in order:
1. The first item is at spot 0, because Python counts from zero.
2. For the last item you can use spot -1.
3. Type: print(crew[0]) and then print(crew[-1])

Answer:
```python
crew = ["Sam", "Thandi", "Lebo", "Ayanda"]
print(crew[0])
print(crew[-1])
```

## Task 2: Grow the shot list
Start with two shots. Add `drone`, then `insert` to the end. Change the first shot to `establishing`. Then print the list, then print how many shots it holds:

`['establishing', 'close', 'drone', 'insert']`
`4`

Hints, in order:
1. Use shots.append("drone") to add to the end. Do it twice, once per shot.
2. To change the first item: shots[0] = "establishing"
3. Finish with print(shots) and then print(len(shots)).

Answer:
```python
shots = ["wide", "close"]
shots.append("drone")
shots.append("insert")
shots[0] = "establishing"
print(shots)
print(len(shots))
```

## Task 3: Is it packed?
The gear list is ready. Ask `Item? `. Print `Packed` if the item is in the list, otherwise print `Missing`. Example with `gimbal`:

`Item? gimbal`
`Packed`

Hints, in order:
1. You need an if and an else. The question is: is item in gear?
2. The test line is: if item in gear:
3. if item in gear: then print("Packed"), else: then print("Missing"). Indent each print by 4 spaces.

Answer:
```python
gear = ["camera", "tripod", "gimbal", "mic", "slate"]
item = input("Item? ")
if item in gear:
    print("Packed")
else:
    print("Missing")
```

## Editor tip (VS Code): Autocomplete
Type a list's name and a dot, and a menu appears with everything a list can do: `append`, `sort` and more. That menu is **autocomplete**. Arrow to one and press Tab or Enter to insert it. You do not have to remember spellings: let the editor offer them.

Try at the PC: Type `shots = ["wide"]` then on a new line type `shots.` and stop. Read the menu. Choose `append`. If the menu ever hides, press Ctrl+Space.
