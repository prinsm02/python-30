# Day 15: Boss: the film quiz game

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Build a quiz game that asks, marks, scores and judges you.

## Key points
- A list of dictionaries is a stack of index cards: loop the list, look up the keys.
- Tidy the player's answer with `.lower().strip()` before you compare.
- A score is a counter: start at 0, `+= 1` for each win.
- You built a whole game from week 1 to 3 tools. Change the cards and it becomes any quiz you like.

## Task 1: Step 1: show the questions
The quiz cards are ready. Loop through them and print each question numbered from 1:

`1. Cinema standard frames per second?`
`2. How many legs does a tripod have?`
`3. The board with the scene number?`

Hints, in order:
1. Numbers and items together means enumerate(quiz, 1).
2. for n, item in enumerate(quiz, 1): then an indented print.
3. print(f"{n}. {item['q']}") (single quotes around q inside the f-string)

Answer:
```python
quiz = [
    {"q": "Cinema standard frames per second?", "a": "24"},
    {"q": "How many legs does a tripod have?", "a": "3"},
    {"q": "The board with the scene number?", "a": "slate"},
]
for n, item in enumerate(quiz, 1):
    print(f"{n}. {item['q']}")
```

## Task 2: Step 2: ask and mark
Ask each question with `input`, using the question and a space as the prompt. Mark it: if the answer (lower case, spaces stripped) matches the card, print `Correct!`, otherwise print `Nope:` and the right answer. Example, answering all three:

`Cinema standard frames per second? 24`
`Correct!`
`How many legs does a tripod have? 3`
`Correct!`
`The board with the scene number? slate`
`Correct!`

Hints, in order:
1. Inside the loop: answer = input(f"{item['q']} ")
2. Compare with: if answer.lower().strip() == item["a"]:
3. The else part: print("Nope:", item["a"])

Answer:
```python
quiz = [
    {"q": "Cinema standard frames per second?", "a": "24"},
    {"q": "How many legs does a tripod have?", "a": "3"},
    {"q": "The board with the scene number?", "a": "slate"},
]
for item in quiz:
    answer = input(f"{item['q']} ")
    if answer.lower().strip() == item["a"]:
        print("Correct!")
    else:
        print("Nope:", item["a"])
```

## Task 3: Step 3: score and verdict
The marking loop is done. Add a `score` that goes up by 1 for each correct answer. After the loop print `Score: 2 out of 3` (with the real numbers), then one final message: all correct prints `Perfect! Frame it.`, at least one correct prints `Good effort. Run it again.`, none correct prints `Back to film school!`

Hints, in order:
1. Set score = 0 before the loop, and score += 1 inside the Correct branch.
2. After the loop use len(quiz) for the total: print(f"Score: {score} out of {len(quiz)}")
3. Then if score == len(quiz): ... elif score >= 1: ... else: ... with a print in each.

Answer:
```python
quiz = [
    {"q": "Cinema standard frames per second?", "a": "24"},
    {"q": "How many legs does a tripod have?", "a": "3"},
    {"q": "The board with the scene number?", "a": "slate"},
]
score = 0
for item in quiz:
    answer = input(f"{item['q']} ")
    if answer.lower().strip() == item["a"]:
        print("Correct!")
        score += 1
    else:
        print("Nope:", item["a"])
print(f"Score: {score} out of {len(quiz)}")
if score == len(quiz):
    print("Perfect! Frame it.")
elif score >= 1:
    print("Good effort. Run it again.")
else:
    print("Back to film school!")
```
