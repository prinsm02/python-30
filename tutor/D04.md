# Day 4: Ask the person a question

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Make programs that ask, then work with the answer.

## Key points
- `input("question ")` pauses, asks, and gives back what was typed.
- `input` always gives text, even for digits.
- `int()` and `float()` turn text into numbers. `str()` turns a number into text.
- `int("seven")` gives a ValueError: it is not a number.

## Task 1: Greet the crew
Ask for a name, then greet them. For the answer `Sam` the screen shows:

`Name? Sam`
`Hello, Sam`

Hints, in order:
1. The answer is already stored in name. Now print it.
2. Use an f-string with {name} inside.
3. print(f"Hello, {name}")

Answer:
```python
name = input("Name? ")
print(f"Hello, {name}")
```

## Task 2: Day rate total
The day rate is R2500. Ask how many days were worked, convert the answer to a whole number, and print the total. For `3` days:

`Days? 3`
`Total: R7500`

Hints, in order:
1. days is text. Turn it into a number first: days = int(days)
2. Then multiply days by rate inside an f-string.
3. print(f"Total: R{days * rate}")

Answer:
```python
days = input("Days? ")
rate = 2500
days = int(days)
print(f"Total: R{days * rate}")
```

## Task 3: Pace from your run
Ask for kilometres, then minutes (both can have decimals, so use float). Print the pace with 2 decimals. For 5 and 28:

`Km? 5`
`Minutes? 28`
`Pace: 5.60 min/km`

Hints, in order:
1. Wrap each input in float(...) so you can do maths with it.
2. Pace is minutes divided by km. Use :.2f for two decimals.
3. print(f"Pace: {mins / km:.2f} min/km")

Answer:
```python
km = float(input("Km? "))
mins = float(input("Minutes? "))
print(f"Pace: {mins / km:.2f} min/km")
```

## Editor tip (VS Code): The Run button and the terminal
The triangle at the top right is **Run**. It opens a panel at the bottom called the **terminal** and tells Python to read your file. The long first line there is VS Code giving that order. Your output comes after it. The terminal is also where input() waits for you to type.

Try at the PC: Open `day3.py` and click the triangle. Read the bottom panel: skip the long line, find your output. Press Ctrl+` (the key under Esc) to hide and show the terminal.
