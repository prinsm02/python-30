# Day 14: Text tools

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Clean, fix, cut and join text, like tidying a messy call sheet.

## Key points
- `.strip()`, `.lower()`, `.upper()`, `.title()` tidy text.
- `.replace(a, b)` swaps pieces. `.split(" ")` makes a list, `" ".join(list)` makes text.
- `in` and `len` work on text. `text[:3]` takes the first three characters.
- Text tools give back new text. Save it or print it.

## Task 1: Tidy one name
The name is messy. Print it tidy, with no spaces at the ends and a capital letter on each word:

`Sipho Naidoo`

Hints, in order:
1. Two tools: one removes the spaces at the ends, one fixes the capitals.
2. They chain: name.strip().title()
3. Type: print(name.strip().title())

Answer:
```python
name = "  sIPHO naidoo  "
print(name.strip().title())
```

## Task 2: Rename the clips
The clips are named `clip_01.mov`. Loop through the list and print each name with `clip` swapped for `ICL`:

`ICL_01.mov`
`ICL_02.mov`
`ICL_03.mov`

Hints, in order:
1. You need a for loop over files, and .replace inside it.
2. for f in files: then an indented print.
3. print(f.replace("clip", "ICL"))

Answer:
```python
files = ["clip_01.mov", "clip_02.mov", "clip_03.mov"]
for f in files:
    print(f.replace("clip", "ICL"))
```

## Task 3: Name and initials
Ask `Full name? ` (two words, any capitals). Print the name tidy in title case, then the initials like `T.D.`. Example with `thandi dube`:

`Full name? thandi dube`
`Thandi Dube`
`T.D.`

Hints, in order:
1. First fix the name with .title(). Then .split(" ") gives you a list of the two words.
2. The first letter of a word is word[0]. So parts[0][0] is the first letter of the first word.
3. print(f"{parts[0][0]}.{parts[1][0]}.")

Answer:
```python
name = input("Full name? ")
name = name.strip().title()
print(name)
parts = name.split(" ")
print(f"{parts[0][0]}.{parts[1][0]}.")
```
