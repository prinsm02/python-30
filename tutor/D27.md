# Day 27: Ask the internet for data

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Read data that another computer sends you.

## Key points
- An API is a data door for programs. You send a request and get a response.
- Most responses are JSON, so `json.loads` and dictionaries do the work.
- Check the status code first: 200 is good, 404 is not found, 500 is their problem.
- At the PC, `requests.get(url)` makes the real request.

## Task 1: Read the response
`weather.json` holds a saved response. Print the city and temperature from the data, like this:

`Johannesburg: 24.5 C`

Hints, in order:
1. The values are inside data. You need data["city"] and data["temp_c"].
2. Use an f-string. Inside it, use single quotes for the keys: {data['city']}.
3. print(f"{data['city']}: {data['temp_c']} C")

Answer:
```python
import json

with open("weather.json") as f:
    resp = json.load(f)

data = resp["data"]
print(f"{data['city']}: {data['temp_c']} C")
```

## Task 2: Check the status first
Never trust data before checking the status. If the status is 200, print `OK:` and the city. Otherwise print `Error` and the status number.

Good response: `OK: Johannesburg`
Bad response: `Error 404`

Hints, in order:
1. You need if / else. The test is resp["status"] == 200 (two equals signs).
2. In the if branch: print("OK:", resp["data"]["city"]). In the else branch: print("Error", resp["status"]).
3. Remember the colon after if and after else, and indent the print lines by 4 spaces.

Answer:
```python
import json

with open("weather.json") as f:
    resp = json.load(f)

if resp["status"] == 200:
    print("OK:", resp["data"]["city"])
else:
    print("Error", resp["status"])
```

## Task 3: Rain on the shoot?
The data has a `forecast`: a list of days, each with `day` and `rain_mm`. For every day with MORE than 5 mm of rain, print `Rain risk:` and the day. At the end print how many days. Example:

`Rain risk: Tue`
`Rain risk: Thu`
`Rain days: 2`

Hints, in order:
1. Use for d in days:. Each d is one dictionary, so d["rain_mm"] is its rain.
2. Inside the loop: if d["rain_mm"] > 5: then print and count += 1.
3. print("Rain risk:", d["day"]) then count += 1, both indented under the if.

Answer:
```python
import json

with open("weather.json") as f:
    resp = json.load(f)

days = resp["data"]["forecast"]
count = 0
for d in days:
    if d["rain_mm"] > 5:
        print("Rain risk:", d["day"])
        count += 1
print("Rain days:", count)
```

## On the PC: Make a real request
You will ask a real computer for the real weather and print one number. This is the same program you wrote today, but live.

1. Open VS Code. If Python 30 Work is not showing, click File, Open Recent, and pick it. Open the terminal with Terminal, then New Terminal.
2. Check the venv is on: the line should start with `(.venv)`. If not, type `.venv\Scripts\Activate.ps1` and press Enter. (If scripts are blocked, use `.venv\Scripts\python.exe` instead of `python` below.)
3. Make the file: click the New File icon at the top of the left panel (a page with a plus), type `api_test.py`, and press Enter.
4. Type this into the file (one URL line, no breaks):

import requests

url = "https://api.open-meteo.com/v1/forecast?latitude=-26.2&longitude=28.04&current_weather=true"
r = requests.get(url, timeout=10)
print("Status:", r.status_code)
data = r.json()
print("Temp in Johannesburg now:", data["current_weather"]["temperature"])
5. Press Ctrl+S to save. In the terminal type `python api_test.py` and press Enter.
6. You should see `Status: 200` and a temperature like 24.1. That number came from a computer far away, just now.
7. If you see ModuleNotFoundError: the venv is not on, go back to step 2. If you see a ConnectionError: check your Wi-Fi and run it again. If Status is not 200, read the number with the table from today's lesson.
8. Try it: change `latitude=-26.2&longitude=28.04` to Cape Town (`latitude=-33.9&longitude=18.42`), save, run again. Different place, different number.
