# Day 2: Give things a name

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Store a value once, then use it anywhere in your program.

## Key points
- `name = value` stores a value under a name. The `=` means store.
- Use a variable by writing its name with no quotes. Store again to change it.
- Names: letters, numbers, underscores, no spaces, not starting with a number.
- An f-string `f"Hi {name}"` puts stored values inside text.
- NameError means Python does not know that name: check the spelling.

## Task 1: Print a stored value
The variable `role` already holds a job. Print it so the screen shows exactly: `Gaffer`

Print the name `role` with no quotes.

Hints, in order:
1. You want print, then brackets, then the name role inside.
2. No quotes around role, or you will print the word role.
3. Type exactly: print(role)

Answer:
```python
role = "Gaffer"
print(role)
```

## Task 2: The call time moved
The crew call moved to 07:30. Change the stored value so the program shows exactly: `Crew call: 07:30`

Change the variable, not the print line.

Hints, in order:
1. Only line 1 needs to change. The print line already uses the variable.
2. Change the text between the quotes on line 1.
3. Line 1 should be: call = "07:30"

Answer:
```python
call = "07:30"
print(f"Crew call: {call}")
```

## Task 3: Slate it
The director wants another take. Change `take` to `"2"` (keep the quotes for now), then print the slate with one f-string so it shows exactly:

`Scene 12, Take 2`

Hints, in order:
1. Store a new value in take on its own line, below the old one: take = "2"
2. Start the print with f before the opening quote. Put {scene} and {take} where the values go.
3. print(f"Scene {scene}, Take {take}")

Answer:
```python
scene = "12"
take = "1"
take = "2"
print(f"Scene {scene}, Take {take}")
```
