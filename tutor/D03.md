# Day 3: Python as a calculator

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Work out totals, pace and groups with numbers.

## Key points
- An int is a whole number, a float has a decimal point. No quotes.
- `+ - * /` and brackets work like a calculator. `/` always gives a float.
- `//` is whole groups, `%` is the leftover.
- `{x:.2f}` in an f-string shows exactly 2 decimals.
- `"5"` is text, `5` is a number. Mixing them gives a TypeError.

## Task 1: Add the hours
A shoot day is 8 hours plus 4 hours of overtime. Print the total so the screen shows exactly: `12`

Use the two variables, do not type 12.

Hints, in order:
1. Use + between the two variable names inside print.
2. print( hours ... extra )
3. print(hours + extra)

Answer:
```python
hours = 8
extra = 4
print(hours + extra)
```

## Task 2: Your pace
You ran 5 km in 28 minutes. Work out the pace (minutes divided by distance) and print it with 2 decimals so it shows exactly:

`Pace: 5.60 min/km`

Hints, in order:
1. Store minutes divided by distance in a new variable called pace.
2. Use an f-string and put :.2f after pace inside the curly brackets.
3. print(f"Pace: {pace:.2f} min/km")

Answer:
```python
distance = 5
minutes = 28
pace = minutes / distance
print(f"Pace: {pace:.2f} min/km")
```

## Task 3: How many vans?
23 crew, 4 seats per van. Print two lines with the numbers worked out by Python:

`Full vans: 5`
`Left over: 3`

Hints, in order:
1. Full vans uses //, left over uses %.
2. You can put a sum straight inside the curly brackets of an f-string.
3. print(f"Full vans: {crew // per_van}") and the same with % for the second line.

Answer:
```python
crew = 23
per_van = 4
print(f"Full vans: {crew // per_van}")
print(f"Left over: {crew % per_van}")
```
