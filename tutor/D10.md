# Day 10: Boss build: Guess the number

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Build a real game: the computer hides a number and you hunt it down.

## Key points
- `import random` borrows the toolbox. `random.randint(1, 20)` picks 1 to 20, both ends included.
- A guessing game is: ask, compare, repeat until right.
- A counter (`tries += 1`) inside the loop counts the rounds.
- `while a and b:` keeps looping only while BOTH are True.
- A seed makes random repeatable, so tests can check it.

## Task 1: Step 1: one guess
The secret is already picked. Ask `Your guess? `, then compare: show `Too low` if the guess is under the secret, `Too high` if over, or `Correct!` if equal. (The checker uses a fixed secret. Just write the comparison.)

Hints, in order:
1. Three roads: below the secret, above the secret, or neither (so it must be equal).
2. if guess < secret: ... elif guess > secret: ... else: ...  Each with a pushed-in print.
3. if guess < secret:
    print("Too low")
elif guess > secret:
    print("Too high")
else:
    print("Correct!")

Answer:
```python
import random
secret = random.randint(1, 20)
guess = int(input("Your guess? "))
if guess < secret:
    print("Too low")
elif guess > secret:
    print("Too high")
else:
    print("Correct!")
```

## Task 2: Step 2: keep guessing
Now keep asking until the guess is right. After each wrong guess show `Too low` or `Too high`. When it is right, show `Correct!` once, after the loop. Start `guess` at 0 so the loop begins.

Hints, in order:
1. The loop runs while the guess is not equal to the secret: while guess != secret:
2. Inside the loop: ask with input, then the if / elif from step 1 (no else this time).
3. while guess != secret:
    guess = int(input("Your guess? "))
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")

Answer:
```python
import random
secret = random.randint(1, 20)
guess = 0
while guess != secret:
    guess = int(input("Your guess? "))
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
print("Correct!")
```

## Task 3: Step 3: the finished game
Make it the full game. Show `Guess my number, 1 to 20` first. Count the tries. Allow 5 tries at most. Win: show `You win! Tries: 3` (with the real number). Out of tries: show `Out of tries. It was 11` (with the real secret). Drop the `Correct!` line.

Hints, in order:
1. Add tries = 0 before the loop and tries += 1 inside it, right after the guess.
2. Loop condition: while guess != secret and tries < 5:  After the loop, an if / else decides the ending message.
3. After the loop: if guess == secret: print(f"You win! Tries: {tries}") else: print(f"Out of tries. It was {secret}")

Answer:
```python
import random
secret = random.randint(1, 20)
guess = 0
tries = 0
print("Guess my number, 1 to 20")
while guess != secret and tries < 5:
    guess = int(input("Your guess? "))
    tries += 1
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
if guess == secret:
    print(f"You win! Tries: {tries}")
else:
    print(f"Out of tries. It was {secret}")
```
