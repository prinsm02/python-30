Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Build a call time adder and a run pace calculator, then join them into one tool.

## Key points
- Small functions that each return one answer are easy to test and combine.
- `strptime`, `timedelta` and `strftime` together move a time forward.
- Pace per km is total seconds divided by km, shown as MM:SS.
- `try` with `except ValueError` and `except ZeroDivisionError` keeps a tool from crashing.

## Task 1: Call time adder
The function `add_minutes` is nearly finished. Replace the `???` so it **returns** the new time as text. Then it must show:

`07:00`
`00:15`

Hints, in order:
1. end is a time. You need to turn it back into text in the shape HH:MM.
2. The tool for turning a time into text is strftime.
3. Replace ??? with end.strftime("%H:%M")

Answer:
```python
from datetime import datetime, timedelta

def add_minutes(clock, mins):
    """Add minutes to an HH:MM time and give back HH:MM."""
    start = datetime.strptime(clock, "%H:%M")
    end = start + timedelta(minutes=mins)
    return end.strftime("%H:%M")

print(add_minutes("05:30", 90))
print(add_minutes("23:30", 45))
```

## Task 2: Run pace tool
Pace per km as `MM:SS`. The line that works out `secs` is a placeholder. Replace `0` with total seconds divided by km, rounded: minutes times 60, divided by km, inside `round(...)`. It must show:

`05:30`
`05:36`

Hints, in order:
1. Change only the line that says secs = 0.
2. Seconds per km is minutes times 60, divided by km. Wrap it in round( ).
3. secs = round(minutes * 60 / km). Check: 55 x 60 is 3300, divided by 10 is 330 seconds, which is 05:30.

Answer:
```python
from datetime import datetime, timedelta

def pace(km, minutes):
    """Give back the pace per km as MM:SS."""
    secs = round(minutes * 60 / km)
    start = datetime.strptime("00:00", "%M:%S")
    end = start + timedelta(seconds=secs)
    return end.strftime("%M:%S")

print(pace(10, 55))
print(pace(5, 28))
```

## Task 3: Race morning planner
Both tools are given. Under the comment, ask `Start time? `, then `Km? ` and `Minutes? `. Show `Pace: ` with the pace and ` /km`, then `Back at: ` with the start time plus the run minutes. Wrap it in `try`: a ValueError shows `Try again`, a ZeroDivisionError shows `Km cannot be 0`. Example: 05:30, 10 km, 55 minutes shows:

`Pace: 05:30 /km`
`Back at: 06:25`

Hints, in order:
1. Start with try:. Inside it, three input lines, then two print lines that call your tools.
2. Km and minutes need int( ) around input( ). The start time stays as text. Then two except blocks lined up with try.
3. print("Pace:", pace(km, minutes), "/km") and print("Back at:", add_minutes(clock, minutes)). Then except ValueError: print("Try again") and except ZeroDivisionError: print("Km cannot be 0").

Answer:
```python
from datetime import datetime, timedelta

def add_minutes(clock, mins):
    """Add minutes to an HH:MM time and give back HH:MM."""
    start = datetime.strptime(clock, "%H:%M")
    end = start + timedelta(minutes=mins)
    return end.strftime("%H:%M")

def pace(km, minutes):
    """Give back the pace per km as MM:SS."""
    secs = round(minutes * 60 / km)
    start = datetime.strptime("00:00", "%M:%S")
    end = start + timedelta(seconds=secs)
    return end.strftime("%M:%S")

try:
    clock = input("Start time? ")
    km = int(input("Km? "))
    minutes = int(input("Minutes? "))
    print("Pace:", pace(km, minutes), "/km")
    print("Back at:", add_minutes(clock, minutes))
except ValueError:
    print("Try again")
except ZeroDivisionError:
    print("Km cannot be 0")
```
