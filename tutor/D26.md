# Day 26: Use other people's code

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Read a manual and use a tool you have never seen.

## Key points
- A module is a ready-made toolbox. Import it and use `module.tool(...)`.
- pip downloads other people's modules. A venv keeps each project's tools separate.
- Read docs for three things: what it does, the exact name, an example.
- You used `statistics` and `textwrap` without ever having seen them. That is the pro move.

## Task 1: Average pace
The docs say: `statistics.mean(data)` returns the average of a list of numbers. Use it on `runs` and show exactly:

`Average: 5.5`

Hints, in order:
1. Write statistics.mean(runs). That one call does the whole sum and divide.
2. Put it inside print, after the word Average: and a comma.
3. print("Average:", statistics.mean(runs))

Answer:
```python
import statistics

runs = [5.5, 6.0, 5.0, 5.5]
print("Average:", statistics.mean(runs))
```

## Task 2: Fair day rate
Five crew quoted day rates. The docs say `statistics.median(data)` gives the middle value. Show the median and the mean, exactly:

`Median: R1500`
`Mean: R1520`

Hints, in order:
1. Two print lines. Each one has an f-string with a call to statistics inside the curly brackets.
2. print(f"Median: R{statistics.median(rates)}") is the first line.
3. The second line is the same but with mean and the word Mean.

Answer:
```python
import statistics

rates = [1200, 1500, 900, 1500, 2500]
print(f"Median: R{statistics.median(rates)}")
print(f"Mean: R{statistics.mean(rates)}")
```

## Task 3: Wrap a call sheet note
From the docs: `textwrap.fill(text, width=70)` adds line breaks so no line is longer than `width`. `textwrap.shorten(text, width=70, placeholder=" [...]")` cuts the text to fit and ends with the placeholder.

Print `note` wrapped at width 28, then print it shortened to width 30 with the placeholder `...`. You should see:

`Crew call is 06:00 at the`
`farm gate. Bring water,`
`sunscreen and your own`
`lunch.`
`Crew call is 06:00 at the...`

Hints, in order:
1. Two calls: textwrap.fill for the first print, textwrap.shorten for the second.
2. Both take note first, then width=. shorten also takes placeholder="...".
3. print(textwrap.fill(note, width=28))
print(textwrap.shorten(note, width=30, placeholder="..."))

Answer:
```python
import textwrap

note = "Crew call is 06:00 at the farm gate. Bring water, sunscreen and your own lunch."
print(textwrap.fill(note, width=28))
print(textwrap.shorten(note, width=30, placeholder="..."))
```

## On the PC: Make a venv and install requests
This is how every real Python project starts: a private toolbox, then the tools it needs. You do it once per project and it takes two minutes.

1. Open File Explorer, open Documents, and check there is a folder called Python 30 Work. If not, right click, New, Folder, and name it exactly that.
2. Open Visual Studio Code (Start menu, type Visual Studio Code, press Enter). Click File, then Open Folder, pick Python 30 Work, and click Select Folder. If it asks Do you trust the authors, click Yes.
3. Open the terminal: click Terminal in the top menu, then New Terminal. A panel opens at the bottom. The last line should end with Python 30 Work followed by a > sign. If it shows a different folder, close VS Code and redo step 2.
4. Type `python --version` and press Enter. You should see `Python 3.12` and some numbers. If it says Python was not found, type `py --version`. If that works, type `py` instead of `python` for the rest of today.
5. Make the venv: type `python -m venv .venv` and press Enter. Wait about 10 seconds. It prints nothing when it works. A new folder called .venv appears on the left. VS Code may pop up a box about the new environment: click Yes.
6. Switch it on: type `.venv\Scripts\Activate.ps1` and press Enter. You should now see `(.venv)` at the start of the line. If you get red text saying running scripts is disabled, do not worry: skip this step and type `.venv\Scripts\python.exe` wherever the next steps say `python`.
7. Install your first outside module: type `pip install requests` and press Enter. Lines scroll past. The last line says `Successfully installed` followed by names. If you skipped step 6, type `.venv\Scripts\python.exe -m pip install requests` instead.
8. Check it worked: type `python -c "import requests; print(requests.__version__)"` and press Enter. A version number like 2.32.3 appears. If you see ModuleNotFoundError, the venv is not switched on: go back to step 6.
9. Bonus: open docs.python.org in your browser, search for statistics, and find the line for `median`. Notice it matches what you used today.
