# Day 12: Loop through a list

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Do something to every item in a list, then total it and rank it.

## Key points
- `for item in mylist:` runs the indented lines once per item.
- `sum`, `min`, `max` do maths on a whole number list.
- `sorted(mylist)` gives an ordered copy.
- `enumerate(mylist, 1)` gives numbers and items together.

## Task 1: Roll call
Say hi to everyone on the crew with a loop. It must show:

`Hi, Sam`
`Hi, Thandi`
`Hi, Lebo`

Hints, in order:
1. Start with: for name in crew:
2. Indent the next line by 4 spaces and print the greeting using name.
3. print("Hi,", name) shows Hi, then the name with a space between.

Answer:
```python
crew = ["Sam", "Thandi", "Lebo"]
for name in crew:
    print("Hi,", name)
```

## Task 2: Day rate totals
These are four crew day rates in rand. Print the total, the highest and the lowest:

`Total: R4450`
`Highest: R1500`
`Lowest: R800`

Hints, in order:
1. Python already has sum(), max() and min() for this. No loop needed.
2. Put them inside an f-string, like f"Total: R{sum(rates)}"
3. Do the same for max(rates) and min(rates), one print line each.

Answer:
```python
rates = [1200, 950, 1500, 800]
print(f"Total: R{sum(rates)}")
print(f"Highest: R{max(rates)}")
print(f"Lowest: R{min(rates)}")
```

## Task 3: Ranked run paces
These are pace times for four runs, in minutes per km. Print them fastest (smallest) first, numbered from 1:

`1. 5.2 min/km`
`2. 5.4 min/km`
`3. 5.8 min/km`
`4. 6.1 min/km`

Hints, in order:
1. You need sorted(paces) to order them, and enumerate(..., 1) to number them.
2. The shape is: for n, p in enumerate(sorted(paces), 1):
3. Inside the loop: print(f"{n}. {p} min/km")

Answer:
```python
paces = [6.1, 5.4, 5.8, 5.2]
for n, p in enumerate(sorted(paces), 1):
    print(f"{n}. {p} min/km")
```
