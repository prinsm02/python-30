# Day 5: Boss build: Mad Libs

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Build a silly story game that uses everything from week 1.

## Key points
- Plan first: ask, convert, tell.
- A `#` comment is a note for humans. Python ignores it.
- Build in small steps and run after each one.
- You can now make a program that talks, asks, calculates and tells a story. That is week 1 done.

## Task 1: Step 1: the opening
Add a comment line (starting with `#`) that says what the program is. Then ask for an animal and a place and print the first line of the story. For `lion` and `Cape Town`:

`Animal? lion`
`Place? Cape Town`
`The lion ran to Cape Town.`

Hints, in order:
1. Ask for the place the same way as the animal. The question is Place? with a space after it.
2. Add a line such as # Mad Libs step 1 at the top, and print with an f-string.
3. print(f"The {animal} ran to {place}.")

Answer:
```python
# Mad Libs step 1
animal = input("Animal? ")
place = input("Place? ")
print(f"The {animal} ran to {place}.")
```

## Task 2: Step 2: add a number
Two more questions: `Adjective?` and then `Number?` (a whole number). The story gets an adjective and a second line that doubles the number. For `lion`, `Cape Town`, `tiny`, `3`:

`The tiny lion ran to Cape Town.`
`It did 3 laps, then 6 more.`

Hints, in order:
1. Ask for the adjective, then the number, in that order, after the place.
2. The number must be an int, so you can do n * 2.
3. print(f"It did {n} laps, then {n * 2} more.")

Answer:
```python
# Step 2
animal = input("Animal? ")
place = input("Place? ")
adj = input("Adjective? ")
n = int(input("Number? "))
print(f"The {adj} {animal} ran to {place}.")
print(f"It did {n} laps, then {n * 2} more.")
```

## Task 3: Step 3: Set Mad Libs
The finished game, film set edition. Print the banner first, ask four questions (`Name?`, `Job?`, `Item?`, `Takes?` where takes is a whole number), then print a three line story. Overtime is R500 per take. For `Zola`, `gaffer`, `lamp`, `4`:

`=== SET MAD LIBS ===`
`Name? Zola`
`Job? gaffer`
`Item? lamp`
`Takes? 4`
`Zola the gaffer arrived with a giant lamp.`
`It took 4 takes to get the shot.`
`Overtime cost R2000. Wrap!`

Hints, in order:
1. Start with print("=== SET MAD LIBS ==="), then four input lines. Convert only Takes.
2. takes = int(input("Takes? ")) lets you do takes * 500 later.
3. The last line is print(f"Overtime cost R{takes * 500}. Wrap!")

Answer:
```python
# Set Mad Libs
print("=== SET MAD LIBS ===")
name = input("Name? ")
job = input("Job? ")
item = input("Item? ")
takes = int(input("Takes? "))
print(f"{name} the {job} arrived with a giant {item}.")
print(f"It took {takes} takes to get the shot.")
print(f"Overtime cost R{takes * 500}. Wrap!")
```

## Editor tip (VS Code): Saved or not saved
Python runs the file on disk, not what you see on screen. A white dot on the file's tab means **not saved**, so Run would use the old version. Ctrl+S saves. Better: switch on Auto Save once and forget about it.

Try at the PC: Type something in `day3.py` and spot the dot on the tab. Press Ctrl+S and watch it go. Then click File and tick Auto Save.
