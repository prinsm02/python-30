# Day 16: Make your own tool

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Give a set of steps one name, then use it as often as you like.

## Key points
- `def name(blanks):` makes a function. Indented lines belong to it.
- Defining does not run it. Calling `name()` does.
- Parameters are blanks. Arguments are the values you fill them with.
- A one-line docstring in triple quotes says what the function does.

## Task 1: Call it three times
The function `cheer` is already written. Under the comment, call it three times so the screen shows:

`Action!`
`Action!`
`Action!`

Hints, in order:
1. To call a function, write its name and brackets: cheer()
2. Write cheer() on its own line, and do that three times.
3. Type cheer() three times, one per line, with no spaces before them.

Answer:
```python
def cheer():
    print("Action!")

cheer()
cheer()
cheer()
```

## Task 2: Fix the slate
The function `slate` prints the wrong thing. Fix the line inside it, then call it for scene 4 take 2, and scene 4 take 3. The screen must show:

`Scene 4, Take 2`
`Scene 4, Take 3`

Hints, in order:
1. Inside the brackets you need both blanks, scene and take. An f-string can hold both.
2. Try print(f"Scene {scene}, Take {take}") and then call slate(4, 2).
3. The two calls are slate(4, 2) and slate(4, 3), on separate lines.

Answer:
```python
def slate(scene, take):
    print(f"Scene {scene}, Take {take}")

slate(4, 2)
slate(4, 3)
```

## Task 3: Gear list tool
Write a function `gear_line(item, qty)` with a one-line docstring. It prints a line like `2 x C-stand`. Then loop over the `gear` dictionary and call your function for each item. The screen must show:

`2 x C-stand`
`6 x Sandbag`
`4 x Flag`

Hints, in order:
1. Two parts. First the def with two blanks. Then a loop with .items() that calls it.
2. Inside the function: print(f"{qty} x {item}"). The loop is: for item, qty in gear.items():
3. Under the for line, indent and write gear_line(item, qty). The docstring is a line of triple quotes right under the def.

Answer:
```python
gear = {"C-stand": 2, "Sandbag": 6, "Flag": 4}

def gear_line(item, qty):
    """Print one gear line."""
    print(f"{qty} x {item}")

for item, qty in gear.items():
    gear_line(item, qty)
```
