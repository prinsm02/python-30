# Day 22: Folders and file names

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** List a card dump, count clips by type and rename them all in one go.

## Key points
- `from pathlib import Path` gives you addresses: `Path("clips")`.
- `.name` is the full file name, `.stem` is without the type, `.suffix` is the type.
- `/` joins a folder and a name. `.exists()` is True or False.
- `sorted(folder.glob("*.mp4"))` lists matching files in a steady order.
- `p.rename(new)` is real. Practise on copies.

## Task 1: List the clips
The folder `day1` has some video files and a log. Show only the file names of the `.mp4` files, one per line. The result for the first test is:

`A001_C001.mp4`
`A001_C002.mp4`

Hints, in order:
1. Printing `p` shows the whole address, with the folder. You only want one part of it.
2. The part with the name and type together is `p.name`.
3. Change print(p) to print(p.name)

Answer:
```python
from pathlib import Path
folder = Path("day1")
for p in sorted(folder.glob("*.mp4")):
    print(p.name)
```

## Task 2: Count by type
The folder `card` has video and sound files. Count them by type and show:

`MP4: 3`
`WAV: 1`

(for the first test files). Use `.suffix` to tell them apart.

Hints, in order:
1. Inside the loop, `p.suffix` is a string like `.mp4`. Compare it with `==`.
2. Use if p.suffix == ".mp4": then add 1 to mp4. Use elif for the .wav files.
3. if p.suffix == ".mp4":  then  mp4 += 1   and   elif p.suffix == ".wav":  then  wav += 1

Answer:
```python
from pathlib import Path
mp4 = 0
wav = 0
for p in sorted(Path("card").iterdir()):
    if p.suffix == ".mp4":
        mp4 += 1
    elif p.suffix == ".wav":
        wav += 1
print("MP4:", mp4)
print("WAV:", wav)
```

## Task 3: Add a prefix to every clip
The folder `raw` has some `.mp4` clips. Rename each one by adding `ICL_` at the front, so `A001.mp4` becomes `ICL_A001.mp4`. At the end show how many you renamed, like:

`Renamed 2`

Hints, in order:
1. `p.rename(...)` needs the new address inside the brackets.
2. The new address is the folder, joined with / to the new name. The new name is "ICL_" plus p.name.
3. Type: p.rename(folder / ("ICL_" + p.name))

Answer:
```python
from pathlib import Path
folder = Path("raw")
n = 0
for p in sorted(folder.glob("*.mp4")):
    p.rename(folder / ("ICL_" + p.name))
    n += 1
print("Renamed", n)
```
