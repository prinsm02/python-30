# Day 23: Spreadsheets with CSV

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Read a rate sheet, add up a column and write a bill file.

## Key points
- CSV is a spreadsheet saved as plain text. Open it with `newline=""`.
- `csv.reader(f)` gives each row as a list. `csv.DictReader(f)` gives each row as a dictionary using the header.
- Every cell is text. Use `int()` or `float()` before adding.
- `csv.writer(f)` and `w.writerow([...])` write a row.

## Task 1: First column
`crew.csv` has a name and a role on each line. Show only the first cell of every row (the header row counts as a row too):

`name`
`Sam`
`Lerato`
`Jo`

Hints, in order:
1. Each `row` is a list. Printing the whole list shows the brackets.
2. You want only the first item of the list. Lists count from 0.
3. Change print(row) to print(row[0])

Answer:
```python
import csv
with open("crew.csv", newline="") as f:
    for row in csv.reader(f):
        print(row[0])
```

## Task 2: Add up the day rates
`rates.csv` has a name and a day rate in rand. Add up the rates and show the total, like:

`Total: R2950`

(Remember: cells are text.)

Hints, in order:
1. Inside the loop, add this row's rate to `total`. The column is called `rate`.
2. The cell is text, so wrap it in int(...) before adding.
3. Replace pass with: total += int(row["rate"])

Answer:
```python
import csv
total = 0
with open("rates.csv", newline="") as f:
    for row in csv.DictReader(f):
        total += int(row["rate"])
print(f"Total: R{total}")
```

## Task 3: Write a bill file
`gear.csv` has `item,days,rate`. Make a new file `bill.csv` with the header `item,cost` and one row per item, where cost is days times rate. For the first test it must be:

`item,cost`
`Light,2400`
`Stand,300`
`Flag,250`

Hints, in order:
1. Loop over `csv.DictReader(f)` inside the inner block, at the same indent as `w.writerow`.
2. Each row needs a list: the item, then days times rate. Days and rate are text, so use int().
3. for row in csv.DictReader(f):  then  w.writerow([row["item"], int(row["days"]) * int(row["rate"])])

Answer:
```python
import csv
with open("gear.csv", newline="") as f:
    with open("bill.csv", "w", newline="") as g:
        w = csv.writer(g)
        w.writerow(["item", "cost"])
        for row in csv.DictReader(f):
            w.writerow([row["item"], int(row["days"]) * int(row["rate"])])
```
