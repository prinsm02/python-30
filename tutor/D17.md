# Day 17: Print is not return

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Make functions that hand back an answer you can use again.

## Key points
- `print` shows an answer on screen. `return` hands it back so you can use it.
- A function with no `return` gives back `None`.
- A default like `rate=150` is used when you leave that value out.
- A function can call another function and use its returned answer.

## Task 1: Hand it back
The function shows 42 but hands back nothing. Change it so it **returns** the answer. The program must show only:

`Answer: 42`

Hints, in order:
1. Look at the line inside the function. It shouts the answer. It needs to hand it back.
2. Change the word print to return.
3. The line becomes: return n * 2 (no brackets needed).

Answer:
```python
def double(n):
    return n * 2

x = double(21)
print("Answer:", x)
```

## Task 2: Week total with a default
Write `day_total(hours, rate=150)` that returns hours times rate. The program lines below it are already written. It must show:

`Week: R3200`

Hints, in order:
1. It is a def with two blanks. The second blank has a default value written as rate=150.
2. The first line is def day_total(hours, rate=150): and the body needs a return.
3. Body: return hours * rate. Check: 8 x 150 is 1200, 10 x 200 is 2000, total 3200.

Answer:
```python
def day_total(hours, rate=150):
    return hours * rate

week = day_total(8) + day_total(10, 200)
print(f"Week: R{week}")
```

## Task 3: Add the VAT
`vat` is finished. Finish `with_vat` so it uses `vat` and returns the amount plus its VAT. The program must show:

`R1150.00`
`R2300.00`

Hints, in order:
1. Inside with_vat you can call vat like any function. Its answer comes back to you.
2. Make total equal amount plus vat(amount). Then add a return line.
3. total = amount + vat(amount) and then return total. The starter crashes because with_vat gives back None.

Answer:
```python
def vat(amount):
    return round(amount * 0.15, 2)

def with_vat(amount):
    total = amount + vat(amount)
    return total

print(f"R{with_vat(1000):.2f}")
print(f"R{with_vat(2000):.2f}")
```
