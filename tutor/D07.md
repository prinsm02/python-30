# Day 7: More than two roads

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Pick from many options and check ranges with elif, and, or, not.

## Key points
- `elif` is else if. Python takes the first road that is True and skips the rest.
- Order matters: check the biggest limit first.
- `and` needs both True. `or` needs one. `not` flips the answer.
- To check a range, join two comparisons with `and`.

## Task 1: Add the middle road
It is 22 degrees. The program should show `Warm` but shows `Cold`. Add an `elif` between the if and the else: when temp is above 15, show `Warm`.

Hints, in order:
1. The new part goes between the if block and the else line.
2. elif works like if: a condition, a colon, then a pushed-in print.
3. elif temp > 15:
    print("Warm")

Answer:
```python
temp = 22
if temp > 30:
    print("Hot")
elif temp > 15:
    print("Warm")
else:
    print("Cold")
```

## Task 2: Day rate label
Ask for hours worked. Show `Double time` if above 12, `Overtime` if above 10 (11 or 12), otherwise `Normal day`. Example:

`Hours? 11`
`Overtime`

Hints, in order:
1. You need one elif and one else under the if that is already there.
2. The elif condition is hours > 10. It is only reached when hours is NOT above 12.
3. elif hours > 10:
    print("Overtime")
else:
    print("Normal day")

Answer:
```python
hours = int(input("Hours? "))
if hours > 12:
    print("Double time")
elif hours > 10:
    print("Overtime")
else:
    print("Normal day")
```

## Task 3: Can we film now?
Ask for the hour (0 to 23), then ask if it is raining (`yes` or `no`). Show `Go shoot` only when the hour is 6 or later AND before 18 AND it is not raining. Otherwise show `Wait`.

Hints, in order:
1. Three questions must all be True, so join them with and.
2. The three questions: hour >= 6, hour < 18, and rain is not yes (use !=).
3. if hour >= 6 and hour < 18 and rain != "yes":
    print("Go shoot")
else:
    print("Wait")

Answer:
```python
hour = int(input("Hour (0-23)? "))
rain = input("Raining (yes/no)? ")
if hour >= 6 and hour < 18 and rain != "yes":
    print("Go shoot")
else:
    print("Wait")
```

## Editor tip (VS Code): Squiggles: errors before you run
A red wavy line under your code is VS Code saying: Python will not be able to read this. It appears while you type, before you run. Hover the mouse over it to read why. All current problems are listed in the **Problems** panel.

Try at the PC: Delete a closing bracket in any file. Find the red squiggle, hover over it, then press Ctrl+Shift+M to open Problems. Put the bracket back and watch it clear.
