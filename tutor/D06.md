# Day 6: Make it decide

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Teach your program to choose: do this if true, do that if not.

## Key points
- `if condition:` runs the indented lines only when the condition is True.
- The colon ends the if line. The 4 spaces show which lines belong to it.
- `==` asks if equal. `!=` not equal. `<` `>` `<=` `>=` compare numbers.
- `else:` runs when the if was False. One road or the other, never both.

## Task 1: Bring water
It is 35 degrees. Under the `if` line, add one pushed-in line (4 spaces) that shows exactly: `Bring water`

Hints, in order:
1. Replace the comment line with a print line. Keep the 4 spaces at the start.
2. The shape is: 4 spaces, then print("your text").
3. Type: (4 spaces)print("Bring water")

Answer:
```python
temp = 35
if temp > 30:
    print("Bring water")
```

## Task 2: Overtime check
Ask for the hours worked. If it is MORE than 10, show `Overtime`. Otherwise show `Normal day`. Example with 12:

`Hours worked? 12`
`Overtime`

Hints, in order:
1. You need if, a condition, a colon, then a pushed-in print. Then else, a colon, a pushed-in print.
2. The condition is hours > 10. Exactly 10 hours is NOT overtime, so use > and not >=.
3. if hours > 10:
    print("Overtime")
else:
    print("Normal day")

Answer:
```python
hours = int(input("Hours worked? "))
if hours > 10:
    print("Overtime")
else:
    print("Normal day")
```

## Task 3: Fix the door code
This door code check has five small mistakes: a wrong `=`, two missing colons and two missing indents. Fix them. If you type `ICL` it shows `Welcome on set`. Anything else shows `Access denied`.

Hints, in order:
1. Fix the first error Python names, run again, repeat. One at a time.
2. To compare you need two equals: ==. Both if and else need a colon at the end. The two print lines need 4 spaces at the start.
3. if code == "ICL":  then a pushed-in print, then else:  then a pushed-in print.

Answer:
```python
code = input("Crew code? ")
```
