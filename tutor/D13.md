# Day 13: Dictionaries: a contact sheet

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Look things up by name, like a contact sheet: name in, phone number out.

## Key points
- A dictionary pairs keys with values: `{"Sam": "0821"}`.
- `d[key]` looks up. `d[key] = value` adds or changes.
- `d.get(key, fallback)` is safe when the key may be missing. A missing key with `[ ]` gives KeyError.
- `for k, v in d.items():` loops through every pair.

## Task 1: Look up two rates
The rate sheet is ready. Print the sound rate, then the gaffer rate:

`1500`
`1800`

Hints, in order:
1. Use the key in square brackets: rates["sound"]
2. Wrap it in print(...), then do the same for gaffer.
3. print(rates["sound"]) and then print(rates["gaffer"])

Answer:
```python
rates = {"gaffer": 1800, "grip": 1200, "sound": 1500}
print(rates["sound"])
print(rates["gaffer"])
```

## Task 2: Update the contact sheet
Change Sam's number to `0999`. Add a new contact, Lebo, with number `0843`. Then print Sam's number and Lebo's number:

`0999`
`0843`

Hints, in order:
1. Changing and adding look the same: phones["Sam"] = ...
2. phones["Sam"] = "0999" changes Sam. phones["Lebo"] = "0843" adds Lebo.
3. After both lines, print(phones["Sam"]) and print(phones["Lebo"]).

Answer:
```python
phones = {"Sam": "0821", "Thandi": "0832"}
phones["Sam"] = "0999"
phones["Lebo"] = "0843"
print(phones["Sam"])
print(phones["Lebo"])
```

## Task 3: Find a contact, then list all
Ask `Who? `. Print that person's number, or `No such contact` if they are not on the sheet. Then print everyone as `Name: number`, one per line. Example with `Thandi`:

`Who? Thandi`
`0832`
`Sam: 0821`
`Thandi: 0832`
`Lebo: 0843`

Hints, in order:
1. Use phones.get(name, "No such contact") so a missing name does not crash.
2. For the full list use: for n, num in phones.items():
3. Inside the loop: print(f"{n}: {num}"). Do the .get line before the loop.

Answer:
```python
phones = {"Sam": "0821", "Thandi": "0832", "Lebo": "0843"}
name = input("Who? ")
print(phones.get(name, "No such contact"))
for n, num in phones.items():
    print(f"{n}: {num}")
```
