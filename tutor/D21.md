# Day 21: Files: read and write

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Make Python read a crew list and write a log file that is still there tomorrow.

## Key points
- `with open(name) as f:` opens a file and closes it for you.
- `f.read()` is the whole file. `for line in f:` is one line at a time. `strip()` cleans each line.
- Mode `"w"` erases and writes. Mode `"a"` adds to the end.
- `FileNotFoundError` means the name or place is wrong. Catch it with try / except.

## Task 1: Read a note
The file `note.txt` is already there. Read it and show everything in it. The result is:

`Bring the ND filter.`
`Charge all batteries.`

Hints, in order:
1. The text is already in the variable `text`. You only need to show it.
2. Add one line at the bottom: print the variable `text`.
3. Type exactly: print(text)

Answer:
```python
with open("note.txt") as f:
    text = f.read()
print(text)
```

## Task 2: Write a call list
`names.txt` has one name per line. Make a new file `callsheet.txt` with one line per name, like this:

`Call: Sam`
`Call: Lerato`
`Call: Jo`

Hints, in order:
1. `readlines()` gives a list of lines. Each still ends with a hidden line break, so clean it with `n.strip()`.
2. Inside the loop use `out.write(...)`. Build the text as "Call: " plus the clean name plus "\n".
3. Type: out.write("Call: " + n.strip() + "\n")

Answer:
```python
with open("names.txt") as f:
    names = f.readlines()
with open("callsheet.txt", "w") as out:
    for n in names:
        out.write("Call: " + n.strip() + "\n")
```

## Task 3: Count, then add a line
Open `shots.txt`. If it is there, show `Shots so far: N` (N is the number of lines in it). If it is missing, show `No shots yet`. Either way, then add the line `Slate 9` to the end of `shots.txt`.

Hints, in order:
1. A `try` must be followed by an `except`. Which error do you catch for a missing file?
2. After the try / except, start a new `with open("shots.txt", ...)` with no indent. Which mode adds to the end?
3. Use mode "a" and f.write("Slate 9\n"). The except line is: except FileNotFoundError:

Answer:
```python
try:
    with open("shots.txt") as f:
        n = len(f.readlines())
    print("Shots so far:", n)
except FileNotFoundError:
    print("No shots yet")
with open("shots.txt", "a") as f:
    f.write("Slate 9\n")
```
