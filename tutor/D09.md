# Day 9: Count with for

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Repeat exactly as many times as you want and add things up as you go.

## Key points
- `for i in range(5):` repeats 5 times, with i = 0, 1, 2, 3, 4.
- `range(1, 6)` gives 1 to 5. The stop number is never included.
- `range(0, 10, 2)` adds a step: 0, 2, 4, 6, 8.
- Running total: set it to 0 before the loop, then `total += value` inside.
- Know the count? for. Do not know when it ends? while.

## Task 1: Five claps
This shows `Clap` three times. Change one number so it shows `Clap` five times.

Hints, in order:
1. range(3) means 3 times. How many times do you want?
2. Change the number inside range( ).
3. Type: for i in range(5):

Answer:
```python
for i in range(5):
    print("Clap")
```

## Task 2: Shoot day total
A crew member earns R1500 a day. Ask how many shoot days, show `Day 1`, `Day 2` and so on, then the total. Example with 2:

`How many shoot days? 2`
`Day 1`
`Day 2`
`Total: R3000`

Hints, in order:
1. You want day 1 up to day days. The stop number is never included, so what must the stop be?
2. Use range(1, days + 1). Inside the loop: print the day, and add 1500 to total.
3. for day in range(1, days + 1):
    print(f"Day {day}")
    total += 1500

Answer:
```python
days = int(input("How many shoot days? "))
total = 0
for day in range(1, days + 1):
    print(f"Day {day}")
    total += 1500
print(f"Total: R{total}")
```

## Task 3: Training plan
A runner starts at 2 km in week 1 and adds 2 km each week, for 5 weeks. Use a loop (week times 2 gives the km). Show every week, then the total:

`Week 1: 2 km`
`Week 2: 4 km`
`Week 3: 6 km`
`Week 4: 8 km`
`Week 5: 10 km`
`Total: 30 km`

Hints, in order:
1. Loop over the weeks with range(1, 6). Inside, work out km from week.
2. km = week * 2, then add km to total, then print the line with an f-string.
3. for week in range(1, 6):
    km = week * 2
    total += km
    print(f"Week {week}: {km} km")

Answer:
```python
total = 0
for week in range(1, 6):
    km = week * 2
    total += km
    print(f"Week {week}: {km} km")
print(f"Total: {total} km")
```

## Editor tip (VS Code): Move, copy and mute a line
Three keys that save retyping. **Alt+Up** or **Alt+Down** moves the line you are on. **Shift+Alt+Down** copies it below. **Ctrl+/** turns the line into a comment and back, which is how you switch a line off without deleting it.

Try at the PC: In any file with three print lines: move the bottom one to the top with Alt+Up, copy a line with Shift+Alt+Down, and mute one with Ctrl+/.
