# Day 25: Boss: shot report and renamer

Tutor notes for a helper model. Explain simply, give a hint before the answer, no em dashes.

**Idea of the day:** Build a tool that reads a shot list, prints a report and renames the clips.

## Key points
- Reading a CSV, reporting and renaming files is one small pipeline: read, report, rename.
- Build in steps and run after each one.
- Check `exists()` before a rename so one missing clip does not crash the job.
- Names like `ICL_S01_T01.mp4` sort in shoot order.
- Always try a new renamer on copies, never on the only copy.

## Task 1: Read the shot list
`shots.csv` has `scene,take,clip,mins`. Show one line for each take, like:

`S01_T01: 10 min`
`S01_T02: 15 min`
`S02_T01: 20 min`

Hints, in order:
1. Join several cells with + and underscores and text, all inside one print.
2. The pieces are: the scene, an underscore, the take, a colon and space, the mins, then " min".
3. print(row["scene"] + "_" + row["take"] + ": " + row["mins"] + " min")

Answer:
```python
import csv
with open("shots.csv", newline="") as f:
    for row in csv.DictReader(f):
        print(row["scene"] + "_" + row["take"] + ": " + row["mins"] + " min")
```

## Task 2: Add the report
Make a tidy report. Start with `SHOT REPORT`, then one line per take, then the number of takes and the total minutes:

`SHOT REPORT`
`S01_T01: 10 min`
`S01_T02: 15 min`
`S02_T01: 20 min`
`Takes: 3`
`Total: 45 min`

The function `code(row)` is done for you.

Hints, in order:
1. Open shots.csv like the last task and loop with DictReader. Start the loop under the `print("SHOT REPORT")` line.
2. In the loop: print the line using code(row), add int(row["mins"]) to total, and add 1 to count.
3. print(code(row) + ": " + row["mins"] + " min")  then  total += int(row["mins"])  then  count += 1

Answer:
```python
import csv
def code(row):
    return row["scene"] + "_" + row["take"]
total = 0
count = 0
print("SHOT REPORT")
with open("shots.csv", newline="") as f:
    for row in csv.DictReader(f):
        print(code(row) + ": " + row["mins"] + " min")
        total += int(row["mins"])
        count += 1
print("Takes:", count)
print("Total:", total, "min")
```

## Task 3: Rename the clips
The finished tool. Keep the report, and for each take also rename the clip `clips/<clip>.mp4` to `clips/ICL_<scene>_<take>.mp4`, for example `A001_C001.mp4` becomes `ICL_S01_T01.mp4`. If the old clip is not there, show `Missing: <clip>` right after that take's report line and carry on.

Hints, in order:
1. You need `from pathlib import Path` at the top. Then build the old address: Path("clips") / (row["clip"] + ".mp4").
2. Ask old.exists(). If True, old.rename(...) to Path("clips") / ("ICL_" + code(row) + ".mp4"). Else print the Missing line.
3. if old.exists(): old.rename(Path("clips") / ("ICL_" + code(row) + ".mp4"))   else: print("Missing:", row["clip"])

Answer:
```python
import csv
from pathlib import Path
def code(row):
    return row["scene"] + "_" + row["take"]
total = 0
count = 0
print("SHOT REPORT")
with open("shots.csv", newline="") as f:
    for row in csv.DictReader(f):
        print(code(row) + ": " + row["mins"] + " min")
        total += int(row["mins"])
        count += 1
        old = Path("clips") / (row["clip"] + ".mp4")
        if old.exists():
            old.rename(Path("clips") / ("ICL_" + code(row) + ".mp4"))
        else:
            print("Missing:", row["clip"])
print("Takes:", count)
print("Total:", total, "min")
```

## On the PC: Run the renamer on a test folder
Now do it for real on your laptop, but only on fake clips. A rename cannot be undone, so you practise on copies in a test folder. Never run this on your real footage. If you ever want to try real clips, copy them first and run it on the copies.

1. Open VS Code. Click File, then Open Folder, and choose `Documents\Python 30 Work`. If the folder is not there, make it in File Explorer first.
2. Open the terminal in VS Code: press Ctrl and the backtick key (the one under Esc). Check it says `Python 30 Work` at the start of the line.
3. Make a test folder: type `mkdir clips` and press Enter.
4. Make three fake clips (tiny empty files, not real footage). Type: `ni clips\A001_C001.mp4, clips\A001_C002.mp4, clips\A001_C003.mp4` and press Enter.
5. In VS Code click New File, name it `shots.csv`, and paste this in: the header `scene,take,clip,mins` then the three lines `S01,T01,A001_C001,10`, `S01,T02,A001_C002,15`, `S02,T01,A001_C003,20`. Press Ctrl+S.
6. Make another new file named `renamer.py`. Paste your finished task 3 code into it and press Ctrl+S.
7. Run it: type `python renamer.py` and press Enter. You should see the report and no errors.
8. Open the `clips` folder in the VS Code side bar. The three files should now be called `ICL_S01_T01.mp4`, `ICL_S01_T02.mp4` and `ICL_S02_T01.mp4`.
9. Run `python renamer.py` a second time. Each line should say `Missing:`, because the old names are gone. That is your safety check working, not a bug.
10. Rule for life: before you ever try this on real footage, copy the whole folder first and run it on the copy. Tick this box when you promise.
